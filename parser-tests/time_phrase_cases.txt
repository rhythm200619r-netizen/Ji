# Ji Time Phrase Parser — Test Cases
# ====================================
# NOTE: The parser only finds time phrases; deciding whether a sentence
# is a real commitment happens in a later stage (Phase 1b / Phase 3 ML).
#
# Format: id|input|reference|expected|comment
#
# - reference : ISO-8601 local datetime used as "now" for resolving relative phrases
# - expected  : ISO-8601 local datetime the parser should resolve to,
#               NONE = no match (or past-tense / irrelevant),
#               NEEDS_TIME = time phrase recognized but lacks a valid future time slot
#
# Rules:
#   - "today" / "aaj" with no time: use the next default slot (09:00, 14:00, 18:00, 21:00)
#     still in the future; if none remain today, return NEEDS_TIME.
#   - Bare weekday that is today: means today if the time is still ahead, otherwise next week.
#   - "next <weekday>": always means next week (strictly after today).
#   - Bare hours disambiguation (no am/pm):
#       Hours 1-6  → assume PM
#       Hours 7-11 → assume AM if on a future day; if same day, use next future occurrence
#       Hour 12    → noon (12:00 PM)
#   - With explicit am/pm: use it; if already past today, advance to next day.
#   - Default time slots:
#       morning (subah/सुबह)       = 09:00
#       afternoon (dopahar/दोपहर)  = 14:00
#       evening (shaam/शाम)        = 18:00
#       night (raat/रात)           = 21:00
#   - "kal/कल" in reminder context defaults to tomorrow. In past-tense phrases ("kal kiya tha"), it refers to yesterday → NONE.
#
# Primary reference: 2024-03-15T10:00 (Friday, 10:00 AM)
# ====================================
